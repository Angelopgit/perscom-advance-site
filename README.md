# PERSCOM Advance — Marketing Website

This is the marketing website for **PERSCOM Advance**, a commercial self-hosted personnel management platform designed for milsim (military simulation) gaming units.

## Overview

The site is a single-file, zero-dependency marketing page built with pure HTML, CSS, and JavaScript. No build step required — just open `index.html` in a browser or serve it from any static host.

## Files

- `index.html` — Complete marketing website (all CSS and JS inline)

## Features

- Framer/Linear-quality design aesthetic
- Dark navy/military-tech visual theme
- Glassmorphism cards with glow effects
- Scroll-triggered reveal animations (IntersectionObserver)
- Animated counter stats
- Parallax hero background with mouse-tracking orbs
- Typewriter effect on hero subtitle
- FAQ accordion with smooth height animation
- Monthly/Annual pricing toggle
- Mobile hamburger menu
- Fully responsive (mobile-first, tested to 375px)
- SEO meta tags and Open Graph tags

## Hosting

Drop the `index.html` file onto any static host:
