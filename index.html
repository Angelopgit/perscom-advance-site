FAQ

Common Questions

Everything you need to know before getting started.

Do I need my own server?
+
Yes — PERSCOM Advance is self-hosted software. You deploy it on your own VPS or server. We recommend DigitalOcean, Hetzner, or Railway for easy deployment. Minimum specs: 1GB RAM, 10GB storage, and a public IP address. Most providers offer suitable servers starting at $5–$7/month.
What happens if I cancel my subscription?
+
Your PERSCOM instance will stop working after your current billing period ends — the license validation will fail and the platform will enter a locked state. All of your data remains safely on your server. If you resubscribe, you can be back up and running immediately with no data loss.
Can I use one license for multiple units?
+
Each license covers a single deployment of PERSCOM Advance. If you run multiple independent units or communities, you'll need a separate license for each instance. If you need multiple deployments, contact us — we offer discounts for multi-unit arrangements.
How do I receive updates?
+
Updates are delivered through Git. Simply run git pull on your server to fetch the latest version, then restart the application. Major updates and release notes are announced in our Discord community server before deployment.
Is my unit's data safe and private?
+
Your data never leaves your server. We have no access to your unit's personnel records, operations data, or any other information stored in your PERSCOM instance. The only external communication is license key validation — a simple ping that confirms your subscription is active. Your data is entirely yours.
What tech stack is required to self-host?
+
PERSCOM Advance requires Node.js 18 or higher, npm, and a Linux server with internet access. That's it. We provide a complete setup guide that walks you through every step, including configuring your Discord bot, setting up your environment variables, and running the application as a system service.
